### D2 微信 4.1.13 的 AX 可读性 —— 最大未知

- 日期：2026-10-15
- 状态：**待验证**
- 背景：微信 Mac 4.0 为客户端重写版本（实测进程模块名 `xwechat_mac`，区别于 3.8.x 架构）。本机实装 4.1.13。**没有该版本 AX 元素树结构的实测数据。**
- 决策：不假设可读。Day 0 先运行 `scripts/spike_ax_dump.py` dump 元素树，据实测结论决定主路。
- 后果：
  - 若 AX 可读 → 按 D1 走 AX 主路。
  - 若 AX 不可读 → 切 A′（截图 + Apple Vision OCR，按气泡左右位置判定收发方向），或降级为「离线核心完整 + 真实接入标注未验收」。
- 相关实测：**待填写**（script 输出摘要 + 结论）。

### D3 FAQ 匹配走本地确定性方案

- 日期：2026-10-15
- 状态：已采纳（待出题方确认）
- 背景：验收要求「自动化测试中 LLM 调用全部 mock，结果确定」。若 FAQ 相似度用 embedding，则引入模型 / API 依赖，破坏确定性。
- 决策：jieba 分词 + BM25 / 字符 n-gram，纯本地实现。
- 后果：无需外部服务；代价是语义泛化能力弱于 embedding，需靠同义词表补足。

### D9 短期记忆不实现 LLM 摘要

- 日期：2026-10-15
- 状态：已采纳
- 背景：题面明确「LLM 对话摘要属于扩展项，本阶段不实现」。
- 决策：短期记忆只有有界近期窗口；长期记忆只保存用户偏好 / 事实，不保存对话摘要。
- 后果：实现中**不得**顺手加上摘要逻辑；README 须声明该限制。
